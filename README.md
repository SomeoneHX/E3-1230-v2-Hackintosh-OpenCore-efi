# macOS 15 (Sequoia) on Ivy Bridge Xeon E3-1230 V2 + RX 570

[![中文](https://img.shields.io/badge/lang-%E4%B8%AD%E6%96%87-blue)](README_CN.md)

This repository contains an OpenCore EFI folder tailored for installing and running macOS 15 (Sequoia) on a legacy desktop with the following hardware:

| Component | Specification |
|-----------|---------------|
| CPU | Intel Xeon E3-1230 V2 (Ivy Bridge, 4 cores / 8 threads, 3.30 GHz base, 3.70 GHz turbo, 69 W TDP) |
| GPU | AMD Radeon RX 570 8 GB (Polaris, Ellesmere) |
| Motherboard | MSI ZH77A-G43 (H77 chipset, LGA1155) |
| RAM | 16 GB DDR3 1600 MHz |
| Storage | SATA SSD (APFS) |
| Ethernet | Realtek RTL8111E |
| Audio | Realtek ALC892 (layout-id 3) |
| USB | Intel 7-series (USB 2.0 / 3.0) |

The configuration uses the `MacPro7,1` SMBIOS for optimal AMD dGPU encode/decode support, and a combination of legacy ACPI power management and AVX2‑workaround kexts to run macOS 15 on the Ivy Bridge platform.

## EFI Overview

### ACPI
- `SSDT-EC-DESKTOP.aml` – Fake Embedded Controller for desktop systems.
- `SSDT-PM.aml` – CPU power management table generated by `ssdtPRGen.sh` with parameters matching the E3-1230 V2 (frequency range 1200-3700 MHz, TDP 69 W).  
  *If your CPU differs, you must regenerate this file.*
- **ACPI Delete Rules** – Drop the OEM `CpuPm` and `Cpu0Ist` SSDT tables to avoid conflicts.

### Kernel Extensions (Kexts)
| Kext | Purpose |
|------|---------|
| Lilu.kext | Arbitrary kext patching engine |
| VirtualSMC.kext | SMC emulator |
| WhateverGreen.kext | GPU patching |
| AppleALC.kext | Audio (layout-id 3) |
| RealtekRTL8111.kext | Ethernet |
| CryptexFixup.kext | Forces installation of Apple Silicon cryptex; required because Ivy Bridge lacks AVX2.0 |
| AMFIPass.kext | Bypass AMFI for unsigned kexts |
| RestrictEvents.kext | Block unwanted system events |
| USBToolBox.kext + UTBMap.kext | USB port mapping (customised for MSI ZH77A-G43) |
| AppleIntelCPUPowerManagement.kext | Legacy CPU power management (replaces XCPM) |
| AppleIntelCPUPowerManagementClient.kext | User‑space client for the above |
| CPUFriend.kext / CPUFriendDataProvider.kext | **Disabled** – kept for reference; do not enable together with the legacy PM kexts |

### Drivers
- HfsPlus.efi
- OpenCanopy.efi (graphical picker)
- OpenRuntime.efi
- ResetNvramEntry.efi

### Key `config.plist` Settings
- **SMBIOS**: `MacPro7,1`
- **Boot arguments**: `alcid=3 -crypt_force_avx`
- **Kernel Quirks**: `AppleCpuPmCfgLock` = `true`, `AppleXcpmCfgLock` = `true`, `DisableIoMapper` = `true`, `PanicNoKextDump` = `true`, `PowerTimeoutKernelPanic` = `true`
- **SecureBootModel**: `Disabled`
- **Vault**: `Optional`

## BIOS Configuration

Before installing, set your motherboard BIOS as follows:

- Load Optimized Defaults, then adjust:
- Internal Graphics: **Disabled** (you have a discrete GPU)
- Primary Graphics Adapter: **PCIe**
- Above 4G Decoding: **Enabled** (if not available, keep `ResizeGpuBars` = -1)
- XHCI Hand‑off: **Enabled**
- Legacy USB Support: **Enabled**
- SATA Mode: **AHCI**
- Boot Mode: **UEFI only** (disable CSM)
- Secure Boot: **Disabled**
- Intel SpeedStep, Turbo Boost, C‑States: all **Enabled**

## Installation Steps

### 1. Create macOS Installer USB
- Obtain the macOS Sequoia installer app (e.g., via `gibMacOS` or App Store).
- Format a USB drive (16 GB or larger) as `Mac OS Extended (Journaled)` with GUID Partition Map.
- Use `createinstallmedia`:
  ```
  sudo /Applications/Install\ macOS\ Sequoia.app/Contents/Resources/createinstallmedia --volume /Volumes/USB
  ```
- Mount the EFI partition of the USB drive and copy **this entire EFI folder** to it.

### 2. Boot from the USB Installer
- Insert the USB, power on, and press the boot menu key (e.g., F11 on MSI boards) to select the UEFI USB entry.
- At the OpenCore picker, select `Install macOS Sequoia`.
- The installer will boot with `-crypt_force_avx` (already in boot-args) to work on the AVX2‑lacking CPU.
- Use Disk Utility to erase your target drive as APFS, then proceed with the installation.
- The system will reboot several times; **each time choose the `Install macOS` entry** (or the newly appeared `macOS` partition) from the OpenCore menu.
- During the entire installation the display will run without GPU acceleration (slow, low resolution). This is normal because the AMD drivers require AVX2 patches that are not yet applied.

### 3. First Boot and Post‑Install
After the final reboot, you will reach the desktop. **Do not sign into iCloud yet.** The system will feel sluggish because neither the GPU nor CPU power management is active.

### 4. Apply OpenCore Legacy Patcher (OCLP)
- Download the latest [OpenCore Legacy Patcher](https://github.com/dortania/OpenCore-Legacy-Patcher).
- Launch OCLP and click **Post Install Root Patch**.
- OCLP will detect your AMD GPU and patch the necessary drivers (e.g., `AMDRadeonX4000.kext`) to work without AVX2 instructions.
- Follow the prompts to apply the patches, then **reboot**.
- After this reboot, the GPU should be fully accelerated (Metal supported).

### 5. Verify / Regenerate CPU Power Management
The EFI already includes a custom `SSDT-PM.aml` for the E3-1230 V2 (generated with `ssdtPRGen.sh`). If you have a different CPU, regenerate it:
```bash
# Example for E3-1230 V2 (adapt base/turbo/TDP for your CPU)
~/ssdtPRGen.sh -bclk 100 -c 1 -f 3300 -lfm 1200 -l 8 -p 'i7-3770' -turbo 3700 -t 69 -x 0 -m iMac13,2
# The resulting file is at ~/Library/ssdtPRGen/ssdt.aml
cp ~/Library/ssdtPRGen/ssdt.aml /Volumes/EFI/EFI/OC/ACPI/SSDT-PM.aml
```
Then enable `SSDT-PM.aml` in `config.plist` under `ACPI -> Add`. Make sure that `CPUFriend.kext` and `CPUFriendDataProvider.kext` remain **disabled**.

### 6. Final Reboot and Verification
- Save your `config.plist`, shut down the computer, then boot again.
- At the OpenCore picker, press the **Spacebar** and select `Reset NVRAM`. The system will reboot.
- Boot normally into macOS.
- Verify GPU acceleration: open `System Information > Graphics/Displays` – Metal should show “Supported”.
- Verify CPU frequency scaling: use **Intel Power Gadget** or run `sysctl -n machdep.xcpm.frequency_vectors`. You should see the frequency dynamically changing between ~1.6 GHz and 3.5‑3.7 GHz depending on load.
- If you changed the SMBIOS model, regenerate serial numbers with `GenSMBIOS` and re‑sign into Apple services.

## Known Issues / Limitations
- **AVX2.0 Missing**: Despite patches, applications that strictly require AVX2 may crash. Test your critical software before relying on this system.
- **System Updates**: Because `CryptexFixup.kext` forces the Apple Silicon cryptex, minor incremental updates may not be possible. You will likely need to download the full installer for each point update.
- **CPU Lowest Frequency**: The idle frequency might hover around 1.6 GHz instead of the theoretical 1.2 GHz. This is a known limitation of the `MacPro7,1` power profile combined with the Ivy Bridge legacy PM path. The system remains fully usable and smooth.
- **USB Port Map**: The included `UTBMap.kext` is specifically mapped for the MSI ZH77A-G43 motherboard. You must create your own USB map using `USBToolBox` on Windows or `USBMap` on macOS if you have a different board.
